# 即兴之书

一个面向中文即兴表演练习的轻量网页工具。打开它，可以随机获取即兴提示、查阅节目规则，或用简短练习热身。

## 包含什么

- **即兴之书**：点击书页，随机抽取一条即兴箴言。
- **灵感机**：
  - 语义模式随机提供东西、地点、关系、职业、情绪、类型、成语、诗句和台词等提示；可切换普通/进阶难度。
  - 音韵模式随机提供声母组合或韵母。
- **节目库**：收录 85 个即兴节目，可按大类、标签和人数筛选；展开条目可查看规则、时长、主持话术、笑点设计与建议词类型。
- **练习室**：目前提供两项专注与情绪热身练习，并保留分类筛选入口。

## 使用

这是一个无需构建步骤的单页应用。克隆仓库后，用浏览器打开 `improv book2.html` 即可：

```bash
git clone https://github.com/Watchcats211/improv-book-XiaQiu.git
cd improv-book-XiaQiu
open "improv book2.html"
```

也可以用任意静态文件服务器启动，例如：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000/improv%20book2.html>。

## 技术说明

- 单个 HTML 文件，样式、数据与交互逻辑均在文件内。
- 使用 Vue 3 Composition API，运行时通过 BootCDN 加载，因此首次打开需要能够访问该 CDN。
- 不依赖构建工具、包管理器或后端服务；随机提示与节目数据目前直接维护在页面源码中。
